# Stand: Version 6 (läuft in Swift Playgrounds)

Diese zwei Dateien sind der funktionierende Stand, den du in Swift Playgrounds nutzt:

- `MyApp_Version6.swift.txt` → Inhalt komplett in **MyApp**
- `ContentView_Version6.swift.txt` → Inhalt komplett in **ContentView**

Die Endung `.txt` verhindert, dass die Dateien im Paket `InvestMind.swiftpm` doppelt kompiliert werden.
Der gleiche Code liegt aufgeteilt in Einzeldateien in `InvestMind.swiftpm/`.
